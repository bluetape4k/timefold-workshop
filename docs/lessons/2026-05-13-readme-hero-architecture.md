# README 대표 이미지와 WIP 갱신

## 배경

Timefold workshop의 루트 README는 짧은 혼합 언어 문서였고 WIP 스냅샷이 없었다.

## 결정

생성한 solver workbench 이미지를 `docs/assets/timefold-workbench.png`에 저장하고,
루트 README는 영어로 유지하며 `README.ko.md`를 추가했다. 또한 할당된 이슈를
바탕으로 WIP 스냅샷을 작성했다.

## 결과

README 언어별 문서가 solver workshop의 목적, 모듈, 아키텍처를 일관되게 설명한다.

## 검증

- 생성한 asset이 `docs/assets` 아래 PNG로 존재하는지 확인했다.
- 두 README 언어판이 모두 해당 이미지 경로를 참조하는지 확인했다.
